# 课程案例配方

覆盖 P31–P40 的9类案例；人物出场分上下两课。它们是按完整音轨转写与选定画面整理的操作说明，尚未在当前 PR 中重建和渲染。公共回查入口见 [source-index.md](source-index.md)。

## 使用约定

先确定素材、切点、音乐事件与画幅，再选配方。以下 `A/B` 是前后画面，`c` 是切点，`f` 是当前序列的帧。课程部分案例为1920×1080、30 fps，基础案例也有25 fps；数帧前检查序列。

课内5帧在25 fps为0.20秒，在30 fps约0.167秒。迁移时先决定秒数，再按当前帧率换算，而不是复制同一帧数。“缩放100”也依赖素材尺寸、此前的适配方式和效果所在层级。

关键帧表描述事件与状态；位置用本项目画幅求值。将每个动画打在指定属性内，防止把内置“运动”与效果“变换”混用。完成后逐帧检查遮罩、接缝、画外覆盖、第一/最后一帧与声音同步。

## 1. 胶片滚动（P31 00:36–06:12）

**目的**：画面缩小、出现胶片间隔、向一个方向卷绕，再恢复下一画面。适合有意采用胶片语汇的段落。

**结构**：V1上A/B相接；V2调整图层分前后两段；可选的胶片框素材另置上层。前半段效果顺序为：裁剪→变换→偏移→高斯模糊。

1. 以切点为界给前后效果留时间。课程先从切点向前留30帧制作一侧，再复制反向处理另一侧；这不是所有项目的固定总时长。
2. 裁剪顶部/底部从0到约5%，课程用3帧让间隔迅速出现。这里的透明间隔用于区别连续卷绕的帧。
3. 在“变换”中将缩放100→80，调整时间缓动，让缩小起段快、随后趋缓。
4. “偏移”的纵向中心连续移动产生卷绕，课程示例量级约4000像素。按高度和想滚过的次数调整；不能把4000当所有画幅的终值。
5. 高斯模糊改为垂直，模糊度从0升到约100或合适强度，遮住最快的滚动与切换。
6. 后半段复用效果栈，让缩放、裁剪、模糊回到正常；偏移终点对齐完整画面。逐项反转状态和时间，不能只把调整图层拖过去。
7. 可选胶片框：先正确抠除中心、对齐视频边框；不透明度可用3帧淡入/淡出，并随画面恢复放大出画。课程框素材不是本skill附带资源。

**检查**：滚动缝隙是否有设计、是否突然反向、切点是否在模糊峰值、终点是否残留偏移/裁剪、框是否误盖主体。按滚动加速、通过和停止事件设计声音。

## 2. 屏幕缩进/穿越（P32 00:25–07:00；后段为补充效果）

**素材**：有透明屏幕窗口的电脑/设备图片，A/B画面，可选暂停图标与取景框。透明窗口若是实黑，应先处理alpha，不能把黑色直接当透明。

**结构**：设备图置上层；屏幕内容置下层并精确适配窗口。需要独立的另一块屏幕时继续在内部叠层。将要一起运动的完整结构嵌套为一个序列，再在外层打位置/缩放。

| 事件 | 外层状态 |
|---|---|
| 起点 | 放大并移动，让A屏幕内容充满输出 |
| 中点 | 缩小揭示设备/嵌套屏幕关系，保留可读的停留 |
| 终点 | 放大并移动，让B屏幕内容充满输出 |

课程以约20帧定位中间时段，再给另一阶段留时间，实际按音乐重音设置。位置与缩放同时调整，速度峰值服务屏幕切换；不要机械复制“M形”曲线。两端必须由画面覆盖要求计算。

需要定格时，对选定素材“添加帧定格”，另留原素材实例以便恢复。前置镜头若完全静止，可加轻微缩小趋势，与穿越动作接续。暂停/取景图标放在应出现的范围，按窗口透视处理；明显有透视的屏幕可用边角定位，这是从P28迁移的做法。

P32 07:47以后补充高斯模糊＋ProcAmp短调整层，以及超级键抠除绿幕花瓣、模糊花瓣、给原片动画蒙版的遮挡转场。这是可选附加段，不是屏幕缩进的必要依赖。

**检查**：屏幕窗口四边、放大后的分辨率、外层与内层缩放关系、帧定格点、位置曲线是否绕行露框。素材不同就重新求构图。

## 3. 立体破碎（P33 00:30–06:50）

**依赖**：Boris FX Continuum 的 **BCC 3D Extruded Image Shatter**。名称由课程约02:35画面确认。它是外置插件；课程演示的安装包不作为依赖获取渠道。先检查当前主机支持、授权和已安装版本，不能声称 PR 原生包含此效果。

**结构**：B在下，A在上；破碎效果加在A上。A已有复杂变速或抠像时先考虑嵌套，再加插件。

1. 搜索 `shatter`，选择有厚度的 `BCC 3D Extruded Image Shatter`，区别于平面破碎效果。
2. 在Shatter组中，自动模式可快速看形态；需要控制破碎起止时，将 **Automate Scatter** 设为 **Manual**，给 **Scatter Time** 打动画。
3. 从完整状态推进到碎片离开画面。先把起止时间对准音乐/动作，再调碎片密度和形状；允许其完整播放，不在破碎中途无意结束片段。
4. **Particle X / Grid Spacing / Shatter Control** 等控制分块外观；变更一个参数就观察结果，不把它们统称为随机种子，也不假设所有版本增大数值都增加碎片。
5. Movement组控制运动；Particles组的 **Extrusion** 控制厚度。按画面判断飞散、下落与厚度，先保持下一镜头可辨认。
6. 下层B应在透明空隙中显现。要做同一画面的碎裂装饰，可让下层为同源画面；这与换到不同B是两种意图。

**无插件时**：可以交付该配方和依赖说明，或用多块蒙版平面碎片近似。后者无法直接等同复现立体厚度、灯光和物理运动。

P33后半另演示两帧垂直模糊、黑场节奏与变换缩放250→110、快门角度200等卡点组合。它们是风格补充，不是破碎本身。

**检查**：插件是否缺失/带水印、素材透明度、完整出画、变速与效果顺序、预览掉帧与最终渲染的区别。

## 4. 切割与动态拼贴（P34 00:55–12:21）

**目的**：A的两个区域沿相反方向离开，B沿相应方向进入。课程先做上下切割，再拓展左右与斜切。

**公共拼贴栈**（P34约02:30–04:30）：

`变换(缩放50) → 镜像0° → 镜像90° → 镜像180° → 镜像270° → 变换(缩放200)`

分别调四个镜像的反射中心，使镜像边缘与中心画面无缝相接。最后200%抵消前面的50%，不是整体放大两倍。效果顺序必须保留。这是课程在PR中搭的镜像扩展，并非承诺存在一个原生名为“动态拼贴”的效果。

**切割步骤**：

1. V1上A/B相接；调整层在切点前后各覆盖一段，课程示例各5帧。先复制一份无效果序列作对照。
2. 前段调整层放上述拼贴栈。最后一个变换加覆盖半幅的蒙版，羽化归零；复制这个变换，给副本使用互补/反转区域，分别控制两半。
3. 对1920×1080案例，两半位置从中心(960,540)出发，分别向y=0和y=1080移动，让它们沿相反方向滑开。新画幅按宽高与实际出画覆盖求值。
4. 后段重建对应关键帧：两半从相对的画外位置回到中心，并与前段的运动方向接续；不要对整条动画直接时间倒放而造成方向反跳。
5. 斜切时改为三角蒙版，同时改变x/y；课程示例以(0,1080)与(1920,0)作为相反方向端点。按当前构图检查，两个端点不是通用预设。
6. 在负责运动的变换内取消使用合成快门角度，示例输入200增加模糊；按可读性、速度和性能调整。

如果当前版本在串联互补效果蒙版时出现区域污染，可改用两个独立嵌套副本，各自蒙版与变换后合成；这是迁移方案，应重新检查接缝，不能声称它是课程原来的图层结构。

**检查**：镜像黑缝、对半蒙版的交界、层级顺序、互补区域是否重叠、终点是否恢复完整B。露缝先修蒙版、效果顺序与覆盖，不用强模糊掩盖。

## 5. 人物出场与文字扫光（P35–P36）

这是一次分层合成：静止人物抠像＋背景＋框/网格＋强调副本＋前后文字＋整体镜头运动。

**P35 00:27–07:50：建立主体与空间**。

1. 选头部和轮廓完整的帧，帧定格。用不透明度钢笔蒙版闭合抠出人物；放大视图细修头发、曲线，按实际素材设羽化。
2. 保留一份无蒙版同源图作背景，独立缩放/构图；不要把背景副本误当抠像完成。
3. 在背景与人物之间放白色颜色遮罩，用反转矩形蒙版形成框区域；可复制并加网格，调细线条与不透明度。
4. 人物做小幅放大、快速起动后趋稳，课程示例缩放约130。框也可用蒙版扩展作开屏，但该动画是课程拓展，不必和所有强运动同时使用。

**P35 07:50–10:11：扩散副本**。

- 复制已抠人物到上层。课程基图为黑白，直接加反转；彩色源若要同样语汇，应先确定黑白处理。
- 在变换中放大（课内示例至180）同时不透明度降到0，形成向外扩散的一层；用快门角度200与时间缓动控制形态。
- 扩散开始、峰值与结束对准事件；保留清晰主体，不让多层副本遮住脸。

**P36 00:21–06:27：强调与扫光**。

1. 人物背后放略大的副本形成边缘强调。课程以反转效果选择红通道获得红色边缘，这依赖原图颜色；可控纯色轮廓可另做着色副本，需标为迁移处理。
2. 基础文字按构图安排；复制一份白色文字放上层，使用窄而羽化的矩形不透明度蒙版。
3. 蒙版路径从字上方移到下方，显露一条高亮扫过。扫光结束若需再次扫，复制高亮层并错开时间。
4. 将同组文字嵌套，外层用位置＋不透明度做入场。人物后方文字、前方文字分层放置；描边字与实心字分别检查遮挡。
5. 箭头等图形可用色彩Tint把黑白同时映射到目标色，再复制错位进入；只有希望整体变色时才把两个端点设为同色。

**P36 06:27–10:34：整体运动**。

顶层调整层加动态拼贴和变换。课程最后变换缩放示例为220→180→210→200→210（前置50%栈使200为恢复状态），旋转约5°→0°，配合短位置偏移。按重音安排峰值，先控制主体可读，再增加晃动；复制例值后检查所有文字是否仍在安全区。

**检查**：头发白边、扩散副本是否被截断、文字扫光是否越出字形、人物与后方字的遮挡、亮色是否失去重点、整体动作是否妨碍阅读。

## 6. 多机位换装与飞入配件（P37 00:48–13:53）

**前提**：多条画面有可用于同步的共同声音或可靠时间参照。课程对同一歌曲的多个舞台版本做音频同步；实际不同编曲、速度、剪辑可能漂移，同歌名不保证自动同步成功。

1. 批量导入→创建多机位源序列→按音频同步→打开内部序列检查起点、中段与末段。选择清晰主音轨，避免换镜头时声音跟着乱切。
2. 检查多机位源序列与输出序列的实际宽高/帧率，统一适配构图。不要采用“永远按最小素材尺寸建序列”的假设。
3. 在节目监视器启用多机位视图；左侧选角度，右侧看输出。在音乐/动作事件切开并换角度，优先寻找手势、脸部朝向和构图相近的两段。
4. 临时加约4帧交叉溶解用于比较人物重叠，调整缩放/位置使五官和身体对齐；完成后删除这个临时过渡。
5. 上层B延伸到A末端，分成几小段分别画无羽化或适当羽化的多边形蒙版，逐区域替换衣服。需要滑动揭示时给蒙版路径打动画。
6. 如先做了对齐用的放大，在转场完成后用足够时间恢复正常构图，课程示例至少约5帧。实际按动作与视线决定。
7. 飞入帽子：复制B，在帽子清晰的一帧定格，抠帽子→必要时嵌套→变换的位置从画外到最终佩戴位置→快门角度示例180。课内用约5帧预先飞入；不能让到位后跳回不同尺度或姿态。
8. 末尾检查还原后的镜头、所有临时蒙版/对齐过渡与副本音轨，避免残留。

P37的短ProcAmp对比度闪动是可选强调。节拍应结合听感与动作；“一律提前卡点”不是通用规律，不能用它替代音画同步。

**检查**：同步漂移、人物轮廓双影、换装区域错位、配件落点、段落间尺度跳变。需要时改用手动对齐，保留稳定主音轨。

## 7. 水滴落下（P38 00:26–06:10）

**素材逻辑**：A含水或相应动机，B为俯视方向，才能支持“水滴向下落”的视觉解释。可在其他语境迁移成圆形变形，但应重新命名表达。

**结构**：B在V1，A末段延长叠在V2；A的变形、圆形蒙版和缩小先在内部完成，随后嵌套，在外层加水面细节。

| 阶段 | 参数/事件 |
|---|---|
| 从正常画面形成液滴 | Lens Distortion曲率从0向-100推进，课程示例约10帧 |
| 加深形态 | 后续约10帧推动Vertical/Horizontal Decentering、Prism等参数，课内示例向100调节；按实际形态校正 |
| 露出B | 关闭 Fill Alpha，确认外部真正透明 |
| 收拢轮廓 | 不透明度椭圆蒙版从覆盖全画幅转为液滴范围，检查节点顺序，避免第一帧已裁掉A |
| 下落消失 | 缩放在约20帧内降到0；缓动决定先悬停后落或直接下落，按动作选择 |

嵌套后：

1. 湍流置换用大小/数量动画增加轻微不规则轮廓；从无明显扰动开始，水滴消失时数量回到0。
2. 油漆桶选择Alpha通道作为填充选择器，用描边模式给透明边缘加细亮边。课程最终采用白色、约10–15像素量级及叠加混合；不要保留调参时的粗红边。
3. 需要时轻提亮度曲线，B从模糊过渡到清楚。老效果若当前版缺失，先确认替代效果的alpha描边/亮度行为。

**检查**：Fill Alpha造成的白底、蒙版时序、缩小支点、轮廓越界、B过早清楚、扰动残留。该方法是形变合成，不是模拟真实水体折射。

## 8. 移动选框与照片墙（P39 00:53–12:31）

**结构由下到上**：黑白/半调背景A副本→彩色A副本（轨道遮罩键）→颜色遮罩（控制彩色窗）→陆续出现的小画面→统一运动层。

1. 颜色遮罩放在指定遮罩轨，裁剪左右侧形成竖窗；课内左右各40%，留下中间20%。裁剪和颜色遮罩位置分别可动画，控制窗口大小与移动。
2. 轨道遮罩键加在彩色A副本，指向颜色遮罩轨，按其alpha形成窗口；移轨后重设指向。下层背景不能引用同一个错误遮罩。
3. 课程背景使用外置 **BCC Halftone**（约02:30画面确认），形成黑白网点。无插件可用黑白/着色效果保留明暗对比，但网点质感不等同复现。
4. 彩色窗可加两个不同方向的投影，按实际边缘与画面亮度调整。投影只用于分层，不应变成粗黑框。
5. 小画面在各自音乐节点出现：变换缩放0→目标比例，轻微不同旋转和位置，附投影。课程先演示5帧再延至约10帧，目标45/50%随素材变化。
6. 小画面运动结束可帧定格延长；原片连续运动有意义时不必定格。复制属性后核对关键帧入点和长度。
7. 顶层调整层的变换做整体位置＋缩放；事件节点在每张照片出现/结束处。先确认镜头要看哪一张，再给坐标，不随机晃动。
8. 调速率让重音附近运动明确，停留段稳定；检查曲线是否产生意外回摆。预览卡顿时渲染该区间后复查。

**检查**：遮罩轨指错、网点压住细节、照片尺度不统一、投影方向混乱、顶层移动导致露边、画面移动时没有明确主体。

## 9. 对角切片“万花筒”（P40 00:29–09:38）

课程标题的“万花筒”以多组互补三角切片依次进入/展开为主，不要求真实光学万花筒模拟。

**基础单元**：一张画面＋颜色遮罩→沿对角线画三角蒙版、羽化归零→轨道遮罩键控制该画面→复制一组并反转遮罩→每个“画面＋对应遮罩”分别嵌套。两片重合应恢复完整画面。

1. 底层保留完整背景。将两个互补嵌套放在其上，分别添加变换。
2. 先确定结束关键帧：两片均在准确拼合位置；再回起点把各片移到相反的画外方向。课程用约10帧完成运动，端点按实际边界求值。
3. 第二组可改另一条对角线形成新的三角切片，起点延后约5帧，再以约10帧进入。用出现顺序形成节奏与层次。
4. 给切片添加适当投影，并按片的位置修方向和柔和度。闭合处若投影形成不需要的黑线，在运动结束处切开并只移除后段投影；保留完整时间，不能删掉有效内容来藏问题。
5. 重复更多组时在**项目面板复制独立嵌套序列**，再进各组更换画面。仅在时间线上复制实例，会继续引用同一序列；若内层仍共享子嵌套，还需检查并复制对应子序列。
6. 替换素材后复制所需轨道遮罩键及变换/投影属性，取消不需要粘贴的参数；按组标签和命名检查素材对应关系。
7. 反向展开可让位置从拼合状态移到画外，切换时衔接静止段和运动段。末尾反转效果在100/60等值间短跳只是课程附加闪屏，按表达需要取舍。

**检查**：互补三角是否满屏拼合、蒙版缝、遮罩/序列共享关系、每组错开的实际秒数、投影闭合黑线、背景空洞。课内约01:00–03:28的初始转写有不清楚段落，已以分段重转写和关键画面补核；参数仍按当前画面验证，不能声称已经实际运行成功。
