## 对原课的限定与修正

| 原课容易被误用的说法 | 技能采用的处理 |
|---|---|
| 一律25fps、素材高帧率会更快等 | 按交付建序列；区分帧率、速度与独立源帧 |
| 帧与场关系倒置 | 隔行一帧由两个场组成 |
| 标题“临时插值”、转写“PRO” | 统一为时间插值；画面确认效果为ProcAmp |
| 所有混合模式只是程度不同 | 使用不同合成公式，按背景/alpha/目的选 |
| 所有速率图都按“坡度陡”判断 | 区分值图与速率图，识别轴再操作 |
| 过渡只能贴两段交界；Ctrl+D必然全加 | 区分两段交界和单段头尾，检查选择和目标轨道 |
| 语音转写仅2024可用、手工复制未知语言包 | 不复述版本断言，使用当前版与官方语言资源 |
| 滚动快门修复可通治补帧果冻 | 区分逐行曝光形变与光流伪影 |
| 一律提前卡点、自动多机位必然对齐 | 听感/动作/同步联合判断，检查全段漂移 |
| 调整图层与嵌套完全等同 | 检查效果顺序、透明度与坐标层级的实际行为 |
| 固定EQ/缩放/像素/帧数直接套用 | 明确例值条件，按素材、画幅、帧率和意图重算 |
| “提供免费素材/插件包”即可自由使用 | 不附未知安装包；独立核对已安装插件与素材许可 |

这些修正是为避免将课程示范、口误或偏好写成通则；不表示已经对当前Adobe全量文档做过独立审核。
