# 内容结构、节奏和声音

本文件是对课程方法的重新组织，不是逐字稿。P号对应 [source-index.md](source-index.md)。标为“迁移说明”的内容用于限定课程示例的适用范围。

## 先决定这条片子为什么成立

P02 00:20–03:10 将画面视为叙事、氛围、主题与节奏的载体；后续讨论音乐、音效、文字和台词。用它检查每个元素是否承担了具体工作：

| 元素 | 在当前片子中确认的问题 |
|---|---|
| 画面 | 给出什么信息？主体是否明确？与前后镜头有什么关系？ |
| 台词/人声 | 是否推动信息或情绪？是否听得清？ |
| 音乐 | 支撑哪个段落的情绪、时代/空间暗示与节奏？ |
| 环境/动作声 | 是否补足空间与动作的可信度？ |
| 文字 | 补充哪项画面无法清楚传达的信息，或如何帮助构图？ |

P03 00:47–06:48 提出观众的“震撼”和“共情”体验；06:48–07:48 提出创作者的关键桥段与桥段连接。实际使用时同时回答：观众此刻应知道/感受到什么，以及哪个镜头或台词让它自然进入下一段。

不要把震撼缩减为快切与大音量，也不要把共情机械等同于慢镜头。课程本身指出两者可共存。

## 选择组织内容的依据

P04 03:50–13:20 讨论以下类型。先选主导关系，再搜素材；不要先堆效果后寻找主题。

| 主导关系 | 先完成什么 | 常见失败 |
|---|---|---|
| 时间/因果线索 | 确定事件顺序、因果与观众需要的信息 | 只压缩剧情，缺少重点 |
| 非线性叙事 | 写清楚主题、回忆/现实等线索，以及每次切换原因 | 打乱顺序后丢失因果和视角 |
| 台词与情绪 | 先收集能表达同一命题的台词，再设计递进 | 只有相近词句，缺少立意和变化 |
| 音乐/动作卡点 | 先确定音乐段落与节拍，再按动作、方向、构图找镜头 | 素材不足、每拍必切、从头到尾同一强度 |
| 歌词与画面呼应 | 选择本身有表达能力的歌词，寻找具体或隐喻关系 | 逐字配图而没有连续表达 |
| 叙事与情绪结合 | 先理解故事，再使信息、音乐、动作和台词共同推进 | 情绪虽强却看不懂发生了什么 |

迁移说明：非线性不天然优于线性；教程、操作展示、纪录或用户明确要求的顺叙，应保留清晰的线性结构。

## 结构与情绪曲线

P05 00:45–02:45 区分整体基调和局部情绪；02:45–05:15 给出结构框架。

- 开头：让观众产生继续看的理由。可用关键画面或预告式台词，但必须与后文兑现的内容相关。
- 叙述：选视角与切入点，用必要画面、台词交代因果。不要把维持理解所必需的信息全剪掉。
- 转折：可以是故事、情绪、台词或音乐的变化；其作用是改变观众的预期。
- 峰值：把最有分量的信息、台词、动作或视听事件放在合适的位置。峰值前需要铺垫与强弱差。
- 收束：让主旨落下，避免未讲完就突然断掉，或多次假结尾。

长片段可以再次进入叙述、转折与峰值，不必一次循环后立即结束。教学、极短片和开放式作品只借用有帮助的部分。

P05 11:32–14:25 的拉片还涉及省略过程、跨时间线呼应、视线连接及音乐峰值。迁移时记录切点前后主体所在位置、运动方向和视觉重心，检查观众的注意力能否顺畅接续。

## 音乐检索与剪接

依据 P02 03:10–10:55、P14 01:15–05:20：先写场景/时代暗示、情绪及段落变化，再形成搜索词。例如“都市夜景、克制、逐渐抬升”，比只搜“好听BGM”更有用。

课程用乐器与地域、时代作联想示例。迁移说明：这不是排他分类，笛子也能用于现代场景；反差配乐可有明确创作意图。判断实际表达关系即可。

P14 05:20–15:35 与 P11 04:40–08:10 提供三类处理：

1. **循环段落**：寻找完整乐句或重复结构，在相近的节拍位置拼接。保留音乐发展所需的层次；不能只凭波形长得相似就判定接缝成立。
2. **编配逐层增长**：删去中间某层后，衔接处可能出现响度、乐器或情绪跳变。试用恒定功率等交叉淡化，再听前后乐句是否连贯。
3. **短起音与长持续音**：鼓、钢琴等明显起音应先对齐节拍，避免交叉淡化造成双击；持续音可以尝试更平滑的淡入淡出。音色差异太大时，短暂留白也可成立。

重新混合工具可延长或缩短音乐，生成的接缝会显示在片段上。其结果未必精确落在目标时长，最后要检查实际出点；延长过多会造成明显重复。不要用它处理需要保留原话的对白。

## 配乐空间与人声主次

P15 00:00–07:18 区分场景中有来源的音乐与后期配乐，并演示室内混响。

- 有源声音：考虑声音来自哪里、听者在哪里、房间与遮挡关系。
- 室内混响：根据空间大小、衰减、早期反射和干湿比例调节。先保留台词可懂度，再增加空间感；干/湿相加100%是课程演示习惯，不是所有效果器的通则。
- 电话音：课程以 FFT 滤波器削弱低频和高频、保留较窄中频作示例（约07:18–09:14）。不同设备和年代的电话效果不同。
- 门外音：课程演示削弱高频以制造遮挡感（约09:14–10:04）。按门的遮挡和距离微调，避免把全部清晰度消掉。
- 配乐盖住人声：先降音乐音量，再考虑适度频率避让（P15 10:10–12:30）。课程示例削弱约200–2000 Hz、约3–6 dB；这只是试听起点。真实人声频谱与可懂度并不限于这个范围，不能全项目套同一条 EQ 曲线。

角色主题音乐可建立识别关系，场景变化可由音乐或环境声提示。反差配乐需有明确目的。不要把波形高峰直接认作重拍：P15 15:15–15:40 特别要求结合听感确认。

## 音效从空间到强调

P16 00:24–08:15 的分类可用于管理素材和设计声音层次：

| 作用 | 举例与放置方法 |
|---|---|
| 环境氛围 | 雨、车流、鸟叫、风；先维持场景连续性，再控制远近 |
| 动作/必要声 | 脚步、开门、碰撞；与动作发生的事件对齐 |
| 短音乐提示 | 角色出现、片头片尾的短动机；避免与台词争夺焦点 |
| 主观情绪 | 上升、重击、低鸣、心跳；表达预期、紧张或冲击 |
| 移动/转场 | 与画面运动的方向、速度和停止事件对应 |

课程常用组合为“上升→重击”：上升为事件蓄势，重击落在动作/切点/揭示上。它不是每个转场都要添加的固定公式。

画面未直接展示的声音也能延伸空间，例如室内听到雨声，或黑场先出现环境声。根据作品的声音风格选择必要层次，不要求给每一个可见物体都配声。

音效库按功能、质感和时长命名，方便检索。课内“免费素材/素材包”的宣传不构成使用许可；实际交付使用有明确授权的素材。
