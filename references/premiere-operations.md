## 工程、面板与序列

P06：工程保存素材引用与编辑关系，序列保存时间线。先建立有明确路径的工程与素材目录，启用合适的自动保存；不要把“绝不存C盘”当成技术要求。磁盘可用空间、缓存位置、整理和备份更重要。

| 面板 | 用来解决什么问题 |
|---|---|
| 项目 | 导入、整理素材箱、建立序列/调整图层/颜色遮罩 |
| 源监视器 | 预看原素材，以 I/O 选择取材范围 |
| 时间线 | 排列片段、轨道和切点，决定最终时间关系 |
| 节目监视器 | 查看当前序列在播放头位置的合成结果 |
| 效果 | 搜索、添加效果或过渡、管理预设 |
| 效果控件 | 修改选中片段的参数、蒙版和关键帧 |

面板关闭时从“窗口”菜单恢复；布局混乱时检查工作区或重置已保存布局。不要把源监视器显示的原片误当成序列输出。

P07–P08 有两条建序列路径：

1. 交付规格明确：先按要求建立序列，再放素材。记录宽×高、帧率、像素长宽比、扫描方式和音频采样率。
2. 以某条素材为基准：从剪辑建立序列，随后检查自动生成的设置是否符合交付。

常规网络项目通常采用方形像素、逐行扫描、48 kHz 音频；横屏1920×1080和竖屏1080×1920只是例子。已有序列正确时，对不同规格素材选择保留既定设置，再处理其构图与缩放。

迁移说明：帧率描述单位时间的帧数，不会自行让播放加快。隔行一帧包含两个场；课程中倒置的说法不采用。像素长宽比与画面宽高比不同。时间码末位为帧，不是百分之一秒；例如25 fps下 `00:00:01:10` 表示1.4秒。

## 时间线和剪辑工具

P09：上方视频轨会覆盖下方不透明部分；透明区域才显示下层。视频可见性、轨道锁定、音频静音/独奏、链接选择、吸附和同步锁定各管不同事情。执行波纹操作前查看目标轨道、同步锁定及锁定状态；执行后检查字幕、音乐、标记和后段片子的时间关系。

标记 M 可落在片段或序列上，取决于当前选择和焦点。固定音乐卡点前确认标记所属对象。删除轨道会影响其片段，不能当成只整理界面的动作。

P10–P12 的默认快捷键如下；当前映射与焦点优先。

| 意图/要保持的量 | 工具与使用方法 | 核查 |
|---|---|---|
| 选择、移动片段 | V；拖动前检查选中集合与链接关系 | 是否误移声音或覆盖其他片段 |
| 切开片段 | C 剃刀，在所需帧切开后切回 V | 是否只切中目标轨道，是否留下单帧碎片 |
| 改片长并推移后段 | B 波纹编辑，拖动片段边缘 | 后续节拍、字幕、同步是否被移动 |
| 移动交界、保留两段总长 | N 滚动编辑 | 两段均有素材余量，整体出点不变 |
| 保留槽位/时长，改内部取材 | Y 外滑（Slip） | 前后切点不变，内部动作选择正确 |
| 用拉长/压短改变速度 | R 比率拉伸 | 实际速度、声音、慢放画质是否可接受 |
| 向前/后选择轨道片段 | A / Shift+A | 查看单轨/多轨模式及选中范围 |
| 裁到播放头并推动后段 | Q / W，波纹修剪 | 播放头、轨道目标和同步锁定正确 |
| 删除空隙并前移后段 | Shift+Delete 波纹删除 | 是否符合时长和卡点限制 |
| 源片取材 | I 入点、O 出点；可单拖视频或音频 | 入出点是否带着所需声音/转场余量 |
| 画形状/文字、移动视图 | P / T / H / Z | 面板焦点、是否正在输入文字 |
| 保存、撤销、重做、导出 | Ctrl+S / Ctrl+Z / Ctrl+Shift+Z / Ctrl+M | 自定义键盘和当前界面为准 |

P13 基础案例顺序：按照交付建立序列→I/O取材→按内容粗剪→布置音乐与标记→整理切点→短调整图层覆盖交界→导出。卡点首先对照实际听到的节奏，波形只作定位辅助。切点前后逐帧检查原片尾部夹带的杂镜头。

## 关键帧、运动与蒙版

P17–P19：位置、锚点、缩放与旋转应分别理解。1920×1080序列中心为(960,540)；锚点是变换支点，其坐标依赖素材/效果空间。节目面板“适合/25%”只是查看比例，不能代替素材缩放。

操作循环：在起点启用属性秒表→移动时间→改数值建立下一关键帧→用前/后关键帧按钮返回节点→调整插值与速率→播放检查。需要停留就复制相同值到另一个时间点。关闭秒表通常会清除该属性动画；删除单个节点与关闭整条动画不同。

**空间插值**控制位置路径走直线还是曲线；**时间插值**控制参数如何随时间变化。课程标题“临时插值”在此统一为“时间插值”。位置路径先保证经过正确区域，再调快慢；拖时间曲线时不要顺带改了空间路径。

- 线性：适合匀速、硬朗或持续平移。
- 贝塞尔/缓动：用于起步、停止、冲击后趋稳等速度变化。按事件决定哪一端快，不是所有关键帧都套同一种缓入缓出。
- 保持：维持前值，直到下一关键帧发生跳变，适合明确的切换。
- 速率曲线的纵轴是变化速率；值曲线的斜率才直接对应变化快慢。先辨认当前图表，避免照抄课程中的“M形/陡坡”手势。

P20–P21：不透明度100%为不透明，0%为透明。钢笔路径要闭合才能限定区域；羽化软化边缘，扩展在不重画路径时增减范围，“已反转”交换内外。静止抠像可先帧定格；运动主体需要动画/跟踪与逐帧修边。安全边距仅是构图辅助线。

效果蒙版只限制该效果作用区域，不等于把整层抠成透明；不透明度蒙版决定整层可见区域。蒙版路径点与时间关键帧不是同一对象。切割、文字扫光等案例须确认蒙版挂在哪个属性下面。

混合模式按不同数学规则合成上下层，不能当成“强弱不同”的同一种效果。滤色常用于黑底光效，正片叠底常用于白底墨迹；检查真实背景、alpha和颜色后再选。调整不透明度可继续控制强度。

## 变速与声音

P22 的时间重映射：时间线片段 fx→时间重映射→速度，添加速度节点，拖速度线改变分段速度；拆开速度关键帧两半可建立过渡区，再调缓动。均匀变速可用“速度/持续时间”，不必先建复杂重映射。改速后检查实际长度与相邻片段，不要把留出的空隙误认为缺失素材。

| 慢放采样方式 | 代价与检查点 |
|---|---|
| 帧采样 | 丢弃/重复帧，慢放可能顿挫 |
| 帧混合 | 融合相邻帧，可能重影 |
| 光流法 | 估计中间运动，遮挡、快速运动和细线条处可能拉扯变形 |

用实际渲染检查，而不只拖播放头。降低速度会减少每秒独立源帧，例如30 fps原片50%速度只有每秒15个独立源帧可用；这不要求把序列改成15 fps。

P23：音频增益和片段音量是相对增减，不是直接把最终响度设为某个dBFS。看电平表并听实际输出；不固定给所有BGM同一负数。片段音量关键帧、轨道推子、声道音量和声像/平衡的控制层级不同。旁路效果不等于删除关键帧。最终应避免非预期削波。

P11、P14–P16 的音乐重混、乐句拼接、混响、电话/门外EQ及音效分类见 [editorial-and-sound.md](editorial-and-sound.md)。本课程没有提供通用响度目标；按平台/交付规范确定，再测量。

## 转写和字幕交接

P24：在当前版本的文本/转录面板选择正确音源和语言→转写→逐句校对→创建字幕→调整分句、时间、样式与安全区域。课程提到的第三方语言包路径不采用；使用当前安装版与 Adobe 提供的语言资源。

删除停顿前先听：呼吸、思考、情绪停留与音画同步可能都依赖这段时间。课内约1–1.3秒的阈值不是自动批删标准。固定总时长、口型同步或不可删原话时，先遵守这些要求。

P25 演示外部工具识别后用 SRT 交接。操作要点：

1. 确定字幕对应的是哪版声音、从哪个时间起算，以及剪辑是否已经锁定。
2. 将 SRT 导入项目并放到时间线。根据任务选择源时间、播放头或时间线起点等放置方式，不默认所有字幕都从第一帧起算。
3. 检查开头、中间、结尾三处同步。有统一偏移时修起点；逐渐漂移时检查音源版本、改速、剪辑和帧率解释。
4. SRT主要传递文本与时间，不保证保留剪映/其他软件的外观。进入 PR 后统一字体、大小、对齐、描边、背景和位置。
5. 修改单个字幕块只作用于该块；统一修改时选择全部或使用当前版本的字幕样式功能。标题动画需要图形层时，先确认转为图形后的编辑和导出需求。
6. 按交付选择烧录字幕、单独SRT或可选字幕轨。课程示范烧录，不代表所有项目必须烧录。导出后实际查看字幕是否出现、是否截断。

文字长度、单行/双行、停留时间以画幅、字号和阅读速度为准；不要机械套课程例子的“20字一行”。

## 效果、调整图层、嵌套与预设

P26：从效果面板搜索关键词，拖到目标片段或对选中片段双击添加；在效果控件改值。fx开关用于前后对照；先确认关闭后画面，再决定是否删除。支持秒表的属性可动画。

**调整图层**：放在需要处理的画面上方，只覆盖想处理的时段；效果作用于下方合成结果。适合跨切点模糊、闪光、整体运动等。字幕、图形如果放在其下也可能被处理。它不在所有情况下等同于嵌套，具体效果与透明度会改变行为。

**嵌套**：将多层合成先作为一个序列，再在外层整体变换。屏幕素材、抠像、已有变速后再叠复杂效果时尤其有用。外层操作与内层操作的顺序会改变结果；先保存备份序列，并清楚命名。

**预设**：选择所需效果及关键帧→保存预设→命名意图、适用画幅/时长→应用到另一个片段检查。当前版本若提供按时长缩放、锚定入点/出点等选项，按效果用途选择；复制预设后重新核对关键帧位置，不能假定新片长会自动正确适配。

P27：恒定功率是常用音频交叉淡化；交叉溶解是视频不透明度过渡。过渡可位于两段交界，也可用于单段头尾；课程“两段必须紧贴才可使用”只适用于跨两段的交界演示。检查可用余量，避免重复帧或冻结。Ctrl+D等默认过渡快捷键受选择、焦点和目标轨道影响，不保证自动覆盖所有切点。

## 效果查找表

P28–P30 是效果巡览，不是完整调色或高级合成课。当前版本可能移动/淘汰老效果；按中英文名称查找，不承诺每个名称都存在。

| 课程中的功能 | 搜索名称/组合 | 用法与限制 |
|---|---|---|
| 翻转与改构图 | 水平/垂直翻转、自动重构图 | 自动结果要复核主体是否被切掉；不用强行变形匹配比例 |
| 去掉边缘、开合画幅 | 裁剪 Crop | 露出的是透明区域；勾缩放可能改变构图/形状，先看alpha |
| 伽马、换色、局部留色 | 灰度系数校正、颜色替换、颜色过滤、黑白 | 相似度会扩大颜色范围，可能误选肤色/背景 |
| 连续滚动 | 偏移 Offset | 可以卷绕图像；接缝可见，胶片案例另加裁剪边框 |
| 画面稳定 | 变形稳定器 Warp Stabilizer | 分析后检查裁切、边缘拉扯和运动意图；效果不宜仅凭教师偏好判定 |
| 带运动模糊的变换 | 变换 Transform | 动画打在该效果内；取消使用合成快门角度后调角度。内置运动属性不自动获得此效果的模糊 |
| 局部放大/旋转/球面 | 放大、旋转扭曲、球面化 | 中心、半径与范围决定目标，确认没有遮掉必要内容 |
| 波浪/不规则变形 | 波形变形、湍流置换 | 分别调高度/宽度/方向或数量/大小/演化；先控制边缘 |
| 四角贴屏幕 | 边角定位 Corner Pin | 对齐四角形成透视；会重采样/变形，原课“不改变内容形变”不能照搬 |
| 镜面重复 | 镜像 Mirror | 反射中心和角度共同决定接缝；用于P34动态拼贴 |
| 镜头形变/透明孔洞 | 镜头扭曲 / Lens Distortion | 曲率、偏移、棱镜参数与 Fill Alpha；水滴案例见配方 |
| 滚动快门校正 | 果冻效应修复 / Rolling Shutter Repair | 针对逐行曝光造成的几何歪斜；不能当作光流补帧伪影的通用修复 |
| 抽帧与拖影 | 抽帧 Posterize Time、残影 Echo | 抽帧不会创造真实中间帧；Echo检查时间采样与效果顺序 |
| 质感与锐化 | 杂色、高斯模糊、方向模糊、锐化、钝化蒙版 | 锐化不能还原不存在的细节；防光晕/噪点。钝化蒙版是锐化效果，不是不透明度蒙版 |
| 模糊边缘管理 | 高斯模糊→重复边缘像素 | 防模糊采样露黑边；不替代大位移所需的画外内容 |
| 生成纹理/背景 | 分形杂色、四色渐变、渐变 | 可在颜色遮罩上生成，再合成；渐变可作背景或创作性着色 |
| 生成光与电 | 镜头光晕、闪电 | 检查光源方向、合成模式与素材风格，不因存在就必加 |
| 审片信息 | 时间码/剪辑元数据与简单文本等烧录效果 | 指明显示源时间或序列时间；终版按交付移除审片信息 |
| 亮度与对比 | ProcAmp、亮度与对比度、色阶、Lumetri颜色 | ProcAmp名称已由P13/P26画面确认；数值按素材，不替代色彩管理 |
| 极端黑白/着色 | 提取 Extract、色彩 Tint、反转 Invert | Tint可映射黑白到两个颜色；Invert是通道数值反转，不仅是色相旋转 |
| 灯光与层次 | 光照效果、基本3D、投影 | 视觉模拟不等于真实3D；投影需合理方向、距离、软硬与叠层 |
| 规则/亮度擦除 | 百叶窗、块溶解、渐变擦除、线性擦除、亮度键 | 用过渡完成或阈值动画；检查是否露出正确的下层 |
| 绿幕/色键 | 超级键 Ultra Key、颜色键 Color Key | 先采样背景，再调容差、边缘与溢色；不可随意抠除同色主体 |
| 任意形状/水墨遮罩 | 轨道遮罩键 Track Matte Key | 效果加在被遮罩素材上，指定遮罩轨；alpha源选Alpha，黑白视频选亮度；需要时反向 |
| 线框弹出 | 查找边缘→色彩→适当混合模式→放大淡出 | 先对照源素材反转与线色，再决定混合方式；P30只作组合示意 |
| 中间值 Median | 遮罩内的局部平滑 | 会损失纹理，不能声称恢复水印遮住的原内容；不把去水印当默认处理 |

课程对SDR遵从、灰片、HDR的解释不足以作为色彩转换流程。遇到Log/HDR时先确定输入色彩空间、序列管理与交付目标，再采用当前版本支持的转换；不要靠随意提高对比度替代转换。

## 导出和故障排查

课程 P13、P25 演示 Ctrl+M、H.264。H.264是编码，MP4是常见封装；按最终交付选择。逐项核对文件名、输出位置、范围、时长、宽高、帧率、音频、字幕、色彩设置，导出后打开成片检查开头、关键切点与结尾。

| 症状 | 先定位，再修改 |
|---|---|
| 效果无变化 | 是否选对片段、fx开启、播放头在覆盖区、参数非默认、层未被上层盖住 |
| 关键帧没动/突然跳 | 秒表是否开启、节点时间/值是否不同、是否保持插值、是否误调另一条属性 |
| 转场露黑/白边 | alpha与Fill Alpha、素材余量、位移/缩放覆盖、镜像接缝、模糊边缘采样 |
| 遮罩显示整块实色 | 是否加在被遮罩层、遮罩轨是否正确、alpha/亮度是否选错、轨道调整后是否重新指派 |
| 卡点都乱了 | 波纹/改速是否推动后段、标记所属对象、同步锁定、字幕/音乐是否跟移 |
| 复制嵌套后改一处全变 | 多个时间线实例引用同一个序列；需要独立内容时在项目面板复制独立序列并核查子嵌套引用 |
| 预览不流畅 | 先渲染目标区间、调整预览分辨率/代理，区分预览掉帧与真实动画顿挫 |
| 导出没有字幕 | 字幕轨可见性、所选导出策略、字体可用性；实际回放输出文件确认 |
| 音量忽大忽小/爆音 | 逐层检查片段增益、轨道效果/推子、接缝与最终电平；不要只看波形高度 |

片内黑场可以是明确设计，不能只因黑色就自动删除。验收依据仍是用户的表达与交付要求。
